No, CPU Temperature Monitor is designed to run as a single instance to prevent conflicts in monitoring data. If you need to monitor multiple systems, consider using separate installations on each machine.

Logs are automatically saved in the "Logs" folder within the installation directory. You can access this through the application's interface or directly via File Explorer. To export data, simply copy the CSV files and open them in Microsoft Excel or similar software.
